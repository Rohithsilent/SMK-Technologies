# SMK Technologies website

This website uses Vite and React. Do not open `index.html` directly from File Explorer; the page needs Vite to load its TypeScript modules.

Program pages are available at `/programs/dsa`, `/programs/web-development`, and `/programs/machine-learning`. Each has an expandable learning roadmap.

## Run locally

1. Open a terminal in this project folder.
2. Run `npm run dev`.
3. Open the local URL printed by Vite (usually http://localhost:5173/).

Keep the terminal running while using the site. The background video and Google Fonts also need an internet connection.
